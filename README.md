# Serenity — Meditation App

A mindful meditation app with mixed media content, progress tracking, personalization, and community features. Built with React + TypeScript + Firebase.

## Features

- **Guided Meditations** — Text-based guided sessions with beautiful imagery (audio/video ready)
- **Progress Tracking** — Streaks, total minutes, weekly charts, mood logging
- **Personalization** — Goals, experience level, preferred duration
- **Community** — Share reflections, milestones, and tips
- **Freemium** — Free content + premium gated meditations

## Getting Started

```bash
npm install
cp .env.example .env   # Add your Firebase config
npm run dev
```

## Tech Stack

- React 19 + TypeScript + Vite
- Firebase (Auth, Firestore, Storage)
- Lucide React icons
- React Router v7
